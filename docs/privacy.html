Privacy policy

Mailean · version 1.1.0 · effective 28/11/2026

What Mailean is

Mailean is a personal tool. Its owner runs it for the owner's own Gmail accounts. It sorts the inbox into six groups, shows a dashboard, and applies actions the owner chooses, such as archive, label, mark read, star, move to Trash and unsubscribe. It is not offered to the public, and nobody else's account is connected to it.

Google user data Mailean reads

Mailean asks for one Gmail permission, gmail.modify. With it, Mailean reads, for messages in the inbox:

  • message and thread ids, labels, and the date received;
  • the sender's name and address, and the subject line;
  • the short preview text (snippet) that Gmail provides, up to 300 characters;
  • the List-Unsubscribe header, when a sender provides one;
  • the text of the message, the To and Cc addresses, the Message-ID header, and the names, types and sizes of its attachments, so the owner can read the email on the dashboard before deciding what to do with it;
  • the attachment files of one email, only when the owner presses Fetch attachments for that email.

Mailean never sends email, and it never deletes mail permanently: "Trash" uses Gmail's own Trash, which Gmail keeps for 30 days.

How the data is used

  • To group each conversation, write a one-line summary, and suggest an action for the owner to review.
  • To show counts and charts on the owner's own dashboard.
  • To let the owner read an email and download its attachments on the dashboard.
  • To apply only the actions the owner queues and confirms.

Mailean does not use Google user data for advertising, does not sell it, and does not use it to develop, improve or train generalised AI or machine-learning models.

Who else processes it

  • Anthropic (Claude API): receives the sender, subject, labels and snippet of new messages, only to classify and summarise them for the owner. It never receives the full text or the attachments. Anthropic's commercial terms govern how it handles these requests.
  • GitHub: runs the agent in the owner's private repository and stores the results there. GitHub Pages serves this website.

No other party receives Google user data. Nobody reads it by hand except the owner.

Where it is stored, and for how long

  • Sign-in keys (OAuth refresh tokens) are stored as encrypted secrets in the owner's private GitHub repository.
  • Triage results (ids, sender, subject, date, group, summary, suggested action) are stored in that private repository on one branch. Each sync replaces the branch, so older results are not kept in its history. Snippets are not stored unless the owner turns that on. Numbers that look like one-time codes are masked.
  • Email text (up to 20,000 characters per email, with numbers that look like one-time codes masked) is stored in the same private repository, only while the email is in the inbox. The next sync after an email leaves the inbox deletes its text. The owner can turn this off; the next sync then deletes all stored texts.
  • Attachment files are copied into the private repository only when the owner asks, and deleted after 7 days, or sooner when the email leaves the inbox.
  • When the owner sets a passphrase, the results, the email text and the attachment files are all encrypted (AES-256-GCM) before they are stored.
  • Deleted texts and files leave the branch's history at the next sync. GitHub decides when it removes replaced versions from its own servers.
  • On the owner's devices, the dashboard keeps the last loaded results, and the email texts the owner opened, so it works offline. Encrypted texts stay encrypted there. Downloaded attachments are saved where the owner chooses. Clearing site data, or Settings → Clear cached inbox, removes the cached results and texts.

How to revoke access and delete data

  1. Remove Mailean's access in your Google Account: Security → Your connections to third-party apps & services.
  2. Delete the MAILEAN_ACCOUNTS secret, or the whole private repository, on GitHub.
  3. In the dashboard, open Settings and choose Forget token and cached inbox.

Limited Use

Mailean's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and changes

Questions go to the owner through the project's GitHub page: github.com/Sathyanarayanan-2001/mailean. Changes to this policy are listed in the project's CHANGELOG, with a new effective date above.
